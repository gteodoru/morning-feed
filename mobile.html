Saturday's biggest story isn't a product launch — it's a proof. The Riemann Hypothesis is now certified correct by machine checking, and the same weekend showed what happens when the checking itself is the hard part: providers caught reading your prompts, and a model that breaks ciphers faster than humans can verify them.

The Riemann Hypothesis proof is certified correct — by machines no human can check by hand

Lean / Mathlib · Nov 21

The Lean community says it has 'full confidence' Alpöge's proof is correct — a 17-million-line library checked by several independent proof checkers. Nobody has read it.

About 10:12 AM ET Saturday, @leanprover posted the joint statement from the Lean FRO and the Mathlib Initiative: 'We have full confidence that Alpöge's proof of the Riemann Hypothesis is correct.' The statement rests on four criteria. The statement is right: RH is already defined in Mathlib and 'has been carefully vetted by experts in Lean and number theory.' The library compiles: dozens of people reproduced the same raw proof export. It proves the right theorem: the community wrote a separate file stating RH and importing only Mathlib, and two independent tools confirmed Alpöge's theorem is exactly that statement — blocking the classic trick of proving a look-alike. And the proof is valid: Lean's kernel, the con-leche and con-ron checkers, and third-party checkers in other languages all accepted it, on 'an inert export of the proof, out of reach of hypothetical malicious code.'

The scale, from MIT's Andrew Sutherland, who ran the checks with Claude Code: 175,187 modules compile with zero errors on Lean/Mathlib v4.33.1; the five headline theorems use only Lean's three standard axioms; the export is 61.6 GB, and a sandboxed rebuild with no network reproduced it byte for byte. The independent Rust kernel nanoda accepted it in 27m42s on 80 threads; con-leche accepted 1,468,418 declarations in 3m15s on 64 threads.

The camps split fast. 'Centaur math: honor the human' — @ElliotGlazer says the 2030 Fields Medal committee should award Levent Alpöge 'or they should disband,' and @trq212 of Claude Code calls collaborating with models to push the frontier 'a deeply technical skill in its own right.' 'An alien wormhole, not theory-building' — @ObhishekSaha expected RH to need 'new theory-building that fills entire books'; instead the proof 'takes an incredibly complicated tour through the infrastructure built for a hundred other mineral reserves.' 'The means of discovery are behind closed doors' — @elder_plinius (7.7K likes): 'these discoveries are being made using models that the rest of us plebs aren't even allowed to know the names of.' And 'does anyone understand it?' — @teortaxesTex asks whether the Claude + Levent room understands the proof at all; @martin_casado answers as a pragmatist: 'If a problem is worth solving, let's solve it with a computer if we must.'

For context: forecasters had RH solved in May 2035 only last month, and Terence Tao had said 'some combination of humans and AIs in 2050 or something.' One useful correction from the replies: RH 'breaks nothing in crypto' — RSA rests on factoring, and ML-KEM on Module-LWE. The deeper point for your work: a proof nobody has read is now accepted on machine checking alone. Trust moves from 'a referee read 25,000 pages' to 'the statement is right, and several independently built checkers agree.' That is a new kind of peer review — and it only works because Mathlib already had a vetted definition of the target. Verification, not generation, is becoming the bottleneck. The same theme runs through the MiniMax story below.

Claude Code's Code Mode: let the model write the glue

Claude Code · Nov 21

One JavaScript program makes all the tool calls, runs steps in parallel, and returns only what the model needs to read — but the permission model changes with it.

A normal coding agent calls one tool at a time: run a search, read the whole result into context, decide, run the next command. On a refactor across 40 files, that's 40+ round trips, and every raw output lands in the context window even when the model only needed one line of it.

In Code Mode, 'Claude writes a piece of JavaScript that makes the tool calls, and Claude Code runs that code in your session.' One program can run commands in parallel, feed one result into the next call, and 'return the part of the output that Claude needs to read.' The docs' example raises a retry limit across files in four tool steps in one turn — and only the file path and test output come back to the model. It can also run long builds or test suites in the background (up to two hours in auto or bypassPermissions mode) while you keep talking. In the chat you still see the diff, not the code; Ctrl+O shows the code as collapsed 'Code' rows.

The safety model is the part worth learning. Each tool call inside the code still goes through your deny/ask rules and PreToolUse hooks under its usual name. But in auto mode, 'the classifier reviews each piece of code before it runs, not each tool call. It doesn't see values computed at run time, such as a path taken from search output.' So keep rules or hooks for calls you must control: a PreToolUse hook matching the tool called REPL can read the code before it runs, or add an ask rule for 'REPL' to approve every program. A hook that allows or blocks shell commands must parse each part of a command — 'a git push in a folder named app can reach your hook as cd 'app' && git push.' And the sandbox covers the shell commands, but 'the JavaScript itself and its file, web, and MCP tool calls run outside the sandbox' — for full isolation, use a container or VM.

How to try it: Claude Code v2.1.323+, native build, interactive terminal, CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1 claude. Models: Opus 5.5, Sonnet 5.5, Haiku 5.5, Fable 5.2. It doesn't work in VS Code, Desktop or cloud sessions, through Bedrock or other gateways, or with zero data retention. One reply from the thread is worth keeping: 'once multi-step tool calls become code, you get diff and rollback for free' — a script leaves something you can read, diff, rerun, and keep afterwards. For the Riot platform work, this is worth enabling with a REPL ask-rule: the audit trail is the feature.

Researchers planted secret links in prompts — and caught inference providers reading them

OpenRouter · Nov 21

Three providers off-boarded, 125 endpoints stripped of zero-data-retention status, after canary links planted in requests were opened 40–130 hours later.

Someone was able to access outputs sent to MiniMax. A researcher found this by planting secret links in requests — and '40 to 130 hours later someone opened the secret links,' as @michael_chomsky summarized it (via @swyx: 'is there any possible benign explanation why these providers were secretly phoning home?'). AltasCloud, Novita and StreamLake 'were forwarding requests to MiniMax,' he wrote — providers 'that should have just been providing inference instead sent your data to another provider… this provider happened to be Chinese, but would have been bad no matter what.'

OpenRouter's response, posted 8:32 PM ET Saturday: 'no breach of OpenRouter itself.' It off-boarded three providers, 'removed 125 endpoints from Zero Data Retention (ZDR) eligibility,' notified affected customers, will run the researchers' test continuously, and is checking network paths for forwarding. It credits a Dragos report and links write-ups from Novita, Phala, and Together ('prompt leakage for requests in June and July of 2026').

The lesson, from a reply translated from Chinese: 'ZDR is only a first-hop promise. Once a request is forwarded to MiniMax or another downstream provider, that label no longer covers it.' Another: 'the canary trick is the elegant part… your prompts pass through providers you never picked.' @Suhail, the same day: Particle is on OpenRouter and 'will never re-route traffic to China or send your data anywhere else.' For anyone routing agent traffic through inference marketplaces — which is exactly what an AI cloud-agent platform does — the takeaway is blunt: a zero-retention promise covers the provider you chose, not the provider they chose.

MiniMax's internal model is breaking ciphers faster than humans can verify the breaks

MiniMax · Nov 21

First practical collisions on SHA-3 candidates, key recovery on post-quantum schemes, 94 McEliece challenge keys — and a 690× gain on Anthropic's HAWK attack.

An internal-only model ('MIM') ran automated cryptanalysis. On CryptanalysisBench Tier 2 — 135 NIST-competition schemes with no known practical attacks — it found the first practical collisions on SHA-3 candidates Waterfall-256 (0.045s) and Blender-256. Key recovery on post-quantum candidates LOCKER (it shrank the solver matrix from 42 PB to 58 MB) and ROLLO-I-128 (~6s). Plus a dozen bugs in reference code, such as DRS, where a mistyped && vs & allowed signature forgery from the public key alone.

On peer-reviewed designs: a forgery on COLM (a CAESAR winner) with two encryption queries; full key recovery on SBC-VOLE (ASIACRYPT 2025) from one signature in 0.06s; ARADI (an NSA 2024 cipher) practical key recovery extended from 5 to 8 rounds. On hard problems: 94 TII McEliece challenge keys (55 previously unsolved), 6,180–43,400x faster than the CRYPTO 2026 record and Anthropic's GPU solver. On HAWK it went 'another 9.3 to 23.8 bits' below Anthropic's attack, recovering a key in 30 minutes on one core.

MiniMax's own framing: 'the bottleneck shifts from discovering attacks to verifying and assessing them.' They say it does not affect deployed standards, and that they disclosed to the authors. The code and traces are at github.com/MiniMax-AI/Research. It is the same theme as the Riemann story that leads this edition: checking the work becomes the hard part — and the checkers now need to be as automated as the provers.

Economists now agree bubbles are real. They still can't time them.

Bloomberg Opinion · Nov 20

Justin Fox: the Journal of Financial Economics never mentioned 'bubble' in its first 28 years. Now it publishes ~14 bubble articles a year — and rapid credit growth means a 40% chance of crisis in three years, vs 7% normally.

One of these days, the long upward run of US stock prices that began in 2009 will come to an end — 'not just with a temporary rotation or drawdown or correction but years of falling valuations and disappointed expectations,' writes Justin Fox. 'Perhaps, with stock indexes mostly down since peaking in early October, it already has.'

What changed is the economics profession itself. The Journal of Financial Economics, which efficient-markets pioneer Eugene Fama co-founded in 1974, avoided all mention of bubbles in its first 28 years; over the past two decades it has published an average of 13.8 articles a year containing the word. A trio of Harvard economists put it this way: while Fama was right that 'a sharp price increase of an industry portfolio does not, on average, predict unusually low returns going forward,' it does signal a much-heightened probability of a crash. Another recent paper found that rapid credit and asset price growth over three years was associated with a 40% chance of a financial crisis in the next three years, compared with a 7% chance in normal times.

What do you do with that? 'Don't sell everything — a 40% chance of a financial crisis in the next three years implies a 60% chance of no crisis.' But don't believe anyone who says the AI boom is different, at least in financial-market terms: railroads, electrification and the internet all transformed the economy, and all were accompanied by painful investment busts. The headline that summed up the mood, from last month: 'Novogratz Joins Crowd Warning of AI Bubble, Says Pile In Anyway.' The honest position is the one the economists landed on: bubbles are real, the warning signs are trackable, and there is no reliable way to time the end — so be prepared for the tide to go out.

A price cut won't fix your churn — and one person should make the call

This Week in Startups · Nov 21

Hormozi cut prices 25% and churn didn't budge — it cost him ~$5M a year. Coinbase's answer to hard calls: one decider, 48 hours, RAPID.

Both of this week's Tactical & Practical posts advise being deliberate rather than jumping in with the obvious fix that feels right in the moment.

First, pricing. Acquisition.com founder Alex Hormozi cut his prices by 25%, betting churn would drop enough to make up the difference. When his churn rate didn't budge, it cost him around $5 million a year in profits. The post works through a quick formula to use before adjusting your own pricing — the point being that churn is usually a value problem, not a price problem, and a discount just charges you for learning that slowly.

Second, decisions. Coinbase President and COO Emilie Choi explains how the company uses the RAPID framework to make speedy, complex decisions: determine the specific list of people who need to be in the room, limit the scope of the conversation, and empower just one person to make the final call — within 48 hours. The temptation with a hard call is to bring everyone together and brainstorm; the discipline is the opposite: fewer people, a narrower question, one decider, a deadline.

From the weekend reads: Ryze AI's Ira Bodnar shared the channel mix that took the autonomous AI marketing company to roughly $10M ARR in about a year — GEO 15% (its #1 priority for 3 months), SEO 10% (how it made its first $1M), paid ads 15%, LinkedIn 10%, X 5%. And Parloa's Malte Kosub on why the agentic customer-service startup prices per minute of conversation or per chat, not per token: customers can't understand value when it comes to tokens. Both are the same lesson as the Hormozi story, from the other side: price the value the customer can see.

Boom test-fired its own supersonic engine — and its first customer may be a data center

Aviation Week · Nov 21

The Superpower core lit on the second attempt and ran to 6,500 rpm on ~2,000 sensors — four years after Rolls-Royce walked away. The same core, minus the fan, is a 42 MW generator.

Test engineers at Boom Supersonic successfully ran the prototype core of the company's in-house developed engine for the first time on Nov. 21 — 'the first full-size jet engine ever built by a startup,' as @snowmaker put it. The first light-off came on the second attempt. 'Prometheus would be proud, we thought there was less than a 50% chance it would work — but on the second try overall we got light off,' founder and CEO Blake Scholl told Aviation Week. 'We ran it up to 6,500 rpm, and we had the benefit of nearly 2,000 real-time sensors.'

The core is the shared heart of two products: the Symphony medium-bypass turbofan for the Mach 1.7 Overture airliner, and the Superpower industrial gas turbine — the same core, minus the fan, driving a 42-megawatt generator. The first application, Scholl has said, is on the ground, not in the sky: behind-the-meter power for AI data centers, deployable in a couple of trailers with no cooling water. Boom is tracking toward tests of a fully integrated engine around the middle of next year, and is setting up an in-house foundry for casting single-crystal turbine blades from custom superalloys.

The backstory is the strategy lesson: Rolls-Royce walked away as engine supplier in 2022, and Boom became, in Scholl's words, 'instantly unfundable.' Building its own engine was the only way forward — and the gap turned out to be the business model, with the turbine as the first revenue product years before any passenger flight. @paulg's one-liner for the weekend captures the VC mood: 'AI will Wallace every Darwin.'

Bloomberg Weekend · Nov 22

Spanish Prime Minister Pedro Sánchez has called a snap general election for Sunday, Nov. 29 — eight months early, after Parliament rejected his minority government's emergency housing measures. It will be Spain's sixth general election in 11 years, for all 350 seats in Congress; 176 are needed to govern.

The people to watch: Alberto Núñez Feijóo, whose conservative People's Party tops most polls and who is favourite to become prime minister; Sánchez himself, written off before and the author of comebacks in 2017 and 2023, who has framed the campaign around the housing crisis; Santiago Abascal, whose anti-immigration Vox sits in a comfortable third and could hold the balance; and Isabel Díaz Ayuso, 48, president of the Madrid region since 2019, who has become one of the most influential figures on the Spanish right — and isn't on the ballot at all. Most polls have the PP and Vox together past 176 seats, though the Socialists have pulled closer in the POLITICO poll average — and the 2023 caution applies: the same polls pointed the same way then, and Sánchez still won a new term 116 days after the vote. A PP–Vox government would shift one of Europe's biggest economies to the right; a Sánchez comeback would be his third escape.

An energy-based perspective on machine learning

Daibond & Du's tutorial, shared by Yann LeCun, who adds that energy-based models are 'MORE GENERAL than probabilistic models.' 'Programming isn't enough anymore'

'Programming isn't enough anymore.' That's Thorsten Ball's argument in Joy & Curiosity #107: when code is cheap, what matters is having something worth building — so learn business, markets, and life outside software. The scarce skill stops being writing the code and starts being judgment about what deserves to exist.
