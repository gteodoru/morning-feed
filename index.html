Anthropic replaced git with Scion because agents now merge 30,000 changes a day

X — @jxnlco · Oct 13

Agent output 12x'd in four months and broke source control, CI and merge queues — the first casualty of code tooling built for humans. Anthropic's answer: a server-side version-control system, built by seven engineers in five months, with a brutally honest "what we learned" section.

In May, Anthropic merged about 2,500 code changes a day. By September it was over 30,000. Main-branch history is nearly 100 GB, a compressed working copy over 25 GB, and the company runs on the order of 25 million CI checkouts a day — fetched naively, over 600 PB a day of git traffic. At peak it ran several hundred internal git mirrors.

The fix: Scion (version control) and Antique (code review), built by seven engineers in five months on the assumption that clients are always online. The server answers history and blame, makes commits, and does merges and rebases; the client keeps only a bounded object cache and lays out files. Every source-control query is also an API, so many CI jobs need no checkout at all. Each commit is a write-ahead-log entry listing files changed versus its first parent, with content-addressed pointers into blob storage — no packfiles, no locks, no cross-server coordination; moving a ref is a compare-and-swap on one Spanner row. Tiered caches (node daemon → regional cache → server, all speaking the same RPCs) hold >99% hit rates. Result: 200x smaller CPU/memory footprint than the git mirrors, checkouts in seconds instead of minutes, a 25% CI capacity win.

The "what we learned" section is the real curriculum for anyone building agent infrastructure. An early Claude Mythos Preview snapshot rewrote their hand-written ingestion pipeline unprompted to use 20x less memory and run 4x faster. Every engineer on the team "would now rate Claude as better at writing code than them." Their job became design trade-offs and telling Claude "no": agents broke core constraints to fit a pattern, and adversarial review made Claude over-engineer. Reviewers now check the intent of a change instead of every line. They gave up the global merge-queue lock for post-merge, pre-deploy testing, since Claude fixes conflicts quickly.

The caveat, stated plainly: Scion is "by no means a suitable replacement for git for general use" and won't be released. Anthropic expects this class of problem to hit everyone else in 6–12 months and wants git forges to adopt server-side RPCs. The first casualty of agent-scale engineering is tooling built for humans.

Fish Audio's Drama 3: open-weight TTS you direct in plain language

X — @FishAudio · Oct 13

An open-weight 35B MoE voice model (3B active) that takes actor-direction in brackets — "[barely holding it together, forcing a smile]" — covers 83 languages, decodes 271 frames/s on one H200, and tops the Artificial Analysis pronunciation benchmark. 8.9M views in a day.

Write direction in square brackets like actor notes — "[barely holding it together, forcing a smile]" — and the model reads it that way. Direction can land mid-line and change the read from that point; paired tags direct only the words inside them; the direction itself can be in a different language from the line. It covers 83 languages.

On Artificial Analysis's Pronunciation Robustness benchmark it scores 93.2% (#1), vs 88.1% for S2.1 Pro, with the biggest gains on brand/place/technical names (95.9 vs 87.3) and context-dependent words (95.3 vs 86.1). The backbone is a 35B MoE with ~3B active (8 of 256 experts plus one shared), initialized from Qwen3.5-35B-A3B; only one layer in four keeps a KV cache. A new codebook-MTP decoder replaces S2's per-frame fast AR, with nine full-width layers, one per acoustic codebook. RL training uses a single learned human-preference reward — the team argues the usual transcribability and speaker-similarity rewards penalize laughs and whispers.

It decodes 271 frames/s on one H200 vs 177 for S2, despite being 7x larger. The API is $10/M characters until November 12 (list $50). License matters here: open-weight, not open source — the Fish Audio Community License is free commercially only below $500K annual revenue, you need a license to offer it as a TTS/cloning service, and cloning a real person without consent is banned. (One correction to the launch-day framing: the "$52M seed" is July news. Drama 3 is the new part.) The technical report is arXiv 2610.18010.

The future of AI coding: explore in parallel, implement once, review in parallel

Decoding AI Magazine · Oct 13

One agent gives one guess with total confidence. Johannes Millan's orchestration playbook — plus Paul Iusztin's "factory engineering" thesis — says the bottleneck isn't generating code, it's your attention verifying it.

Ask one AI agent to fix a bug and you get one guess, delivered with total confidence. The better workflow from Johannes Millan — creator of Super Productivity, whose latest project Parallel Code is an MIT-licensed desktop app for coordinating CLI coding agents in isolated git worktrees: explore the problem in parallel, implement once, review in parallel, then refine and review until the result is trustworthy. More inference, less programmer attention.

The mechanics: before any code is written, several different models inspect the task and repository independently — different model families inspect different execution paths and challenge each other's assumptions. Each returns its understanding, evidence from files and symbols, a proposed solution, alternatives considered, affected components, risks, and tests that should fail before and pass afterward. Comparing several short proposals is much cheaper than comparing several finished 400-line diffs. The developer or a lead agent picks one approach on evidence: does it address the cause rather than the symptom, is the change in the correct layer, is there a smaller solution, does the codebase already have the pattern? Then implement once — and review in parallel.

Paul Iusztin, restacking Zach Lloyd's AI Engineer talk, frames the same shift at the job level: "software engineering is slowly becoming factory engineering." Agents pick up issues, write specs, implement, review, verify, ship — then monitor production, learn from the results, and feed it back so the factory gets better. The engineer's job moves up a level, to judgment. Lloyd — 20+ years, ex-Google principal, led engineering for Google Docs — hasn't written a line of code in 6 months and still ships frequently. The lesson for agent builders: stop optimizing code generation and start optimizing the verification loop.

Satya Nadella, Monday: "Today we are announcing our biggest bet yet on our own silicon. Starting next calendar year, we will scale our Maia family to multi-gigawatt deployments, making it the primary inference system for our own product and services. And we're introducing Maia 300."

Chamath's gloss on the announcement: "You should expect the silicon chip companies to move up the stack as the application companies move down the stack. The WSJ’s Asa Fitch (Oct 13) names the deeper shift: as transistor shrinking slows and advanced fabrication costs keep rising, the new battleground is “advanced packaging” — laying out and stitching together chip components to maximize AI number-crunching. TSMC, AMD and Intel have all leaned in; Nvidia relies on TSMC’s packaging for its market-leading chips. Applied Materials’ CEO said packaging-related spending is becoming a bigger driver of the equipment business; TSMC reports quarterly results Thursday.

Ray Dalio: the numbers behind the bond bear market

LinkedIn — Ray Dalio · Oct 13

Sixteen months after "How Countries Go Broke," Dalio says the numbers are tracking his template: countries go broke when debt supply overwhelms demand and debt service painfully squeezes incomes. Now with equities in the frame.

Sixteen months after publishing "How Countries Go Broke," Dalio is compelled to lay it out again — because, he writes, the progression of the numbers and the bond market has been "broadly consistent with the template and projections." JEPA-style methods prevent representation collapse after the projection head, but downstream tasks use the backbone — which can stay low-rank. The theory: in a two-layer linear net, negative λ-balance guarantees a full-rank encoder, and weight decay plus a −log det term drives training there exponentially fast.
