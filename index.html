Meta's Muse Spark Open: 816B open weights that run on two Mac Studios

X — @AIatMeta · WSJ · Oct 15

The most capable US open-weight model to date — 816B parameters with 42B active, natively multimodal, 1M context — with day-one support in every major inference engine and an Apple partnership to run it locally on Macs.

What it is: a mixture-of-experts language model (62 layers, 256 experts per layer, 8 routed per token — the experts hold ~97% of the parameters) that computes like a 42B model but needs memory like an 816B one. It takes text, images, audio (one token per 80ms) and video (2 FPS with timestamps) in, outputs text, and carries a 1M-token context. Reasoning uses the Harmony channel format (reasoning, commentary, answer) with effort settings up to xhigh — and it can't be fully disabled. It's the full-size sibling of Muse Glimmer, the dense model Meta released in August, sharing its tokenizer.

Why two Mac Studios: MoE sparsity means only the active slice of weights is read per token, so Meta tuned it for two M5 Ultra Mac Studios (512GB unified memory each) via MLX. Apple's updated MLX toolkit supports it, and Meta's on-device demos ran Muse Code on the model to ship real iOS changes and drive DaVinci Resolve end to end. Day-one support landed in llama.cpp (within ~30 minutes of release), vLLM, SGLang, MLX and Transformers, plus seven hosted APIs. A 2-bit quant runs at ~18 tokens/s on a single M3 Ultra.

The catch is the license: the 'Muse Model License' carries branding requirements, a revenue gate and acceptable-use restrictions — Nathan Lambert: 'The Meta Muse Open License is trash.' The WSJ adds balance: Meta acknowledged Chinese open models (Qwen, DeepSeek, Kimi K3) remain superior for software development, and the desktop path needs 1TB+ of memory — upward of $40,000 in Macs. Still, Lambert's verdict: this cuts the US-China open-weights gap 'by at least half.'

Sakana's Agentic Scientist v3: orchestrate the coding agents, don't replace them

X — @SakanaAILabs · Oct 15

The research version of the orchestrator/worker pattern: parallel coding agents with rubric-graded experiments, shared memory and an evidence-mapped paper — with peer-reviewed output at ALIFE 2026.

The problem v3 targets: earlier AI-scientist versions automated a lot of research but produced underdeveloped ideas and buggy implementations — without structure, an 'AI scientist' collapses into 'a strong hyperparameter optimizer in code space.' So v3 wraps existing coding agents (Codex, Claude Code, OpenCode, Pi) in a scaffold that controls what they see and write, how they're judged, and what passes to the next stage: executable task specs with verifiable evaluators, a controller handing fixed research budgets to parallel workers, ideation and execution agents, shared memory with periodic context resets, controlled ablations, and a writer that produces LaTeX with an explicit evidence map from each claim to its source.

Results: an early version helped extend Error Diffusion (a biologically inspired alternative to backprop) from binary classification to multiclass and then RL — humans set the question, verified code and results, caught a reward-hacking candidate the system had scored highly, and the paper was accepted as an ALIFE 2026 oral. Across 5 tasks × 14 model-harness combos, newer models scored higher and the harness mattered less than the model. The honest number: reviewer scores track real results only at r = 0.44 — automated review is a weak signal, and humans remain the referees. The code is open source; stated limits include literature search only at writing time and no pipeline for reproducing strong published baselines.

$300K to break the agents: the industry's prompt-injection contest

X — Gray Swan · Boris Cherny · Oct 15

Anthropic, Meta, Google DeepMind and Reflection AI co-sponsor a public red-team contest for tool-using agents — 10 scenarios, 14 models — because the ChatGPT-in-your-tabs era makes injection the attack that matters.

'Indirect Prompt Injection: Black' is live on Gray Swan's Arena, with a $300K prize pool, white-box and black-box modes, and points weighted by model and scenario difficulty. Claude Code lead Boris Cherny: 'As agents do more, it is increasingly urgent that we solve it across the industry.' The March round drew 13 models, 464 red-teamers and 272K+ attacks.

Why indirect injection is the one that matters: the attacker never talks to the agent. They plant instructions in something it will read — a web page, calendar invite, PDF, code comment or tool result — and an agent with email, browser and payment access may follow them. That's the exact threat model for ChatGPT acting in your signed-in tabs and every always-on agent.

Builder wisdom from the threads: assume it fails and design for it — human approval before anything with consequences, least privilege, keep credentials out of the model's context so a successful injection has nothing to steal. Skeptics counter that competitions find attacks 'we already know how to describe,' while real production injection is slow and context-specific — and an agent that dodges injection by refusing the job 'isn't much use.'

'Neural networks are already clean': the interpretability fight of the day

X — @nickcammarata · Oct 15

Ex-OpenAI circuits researcher Nick Cammarata argues superposition was partly a bad microscope — and the field's elders say: interesting, but don't over-update.

The essay (2.46M views, published by Goodfire) argues that famous 'polysemantic' neurons were misread — a neuron that seemed to fire for cats and cars responds to a shared V shape — and that with better tools and modern architectures, layers that looked tangled became legible. Preliminary audits of Qwen3-32B suggest ~90% of neuron poles have one main job. His method: inspect original neurons, write explanations, then ablate components to see whether predicted behavior follows — explanations that 'could lose.' He puts ~98% on 'there's good news' but only ~60% that simple methods go all the way, and claims interpretability 'was mostly hopeless before agents' and is now 'largely doing a ton of relatively easy natural science.'

Pushback from inside interpretability: Neel Nanda — 'interesting work, but I don't think it's a significant update to the big picture'; Leo Gao: 'if you can't simulate a neuron you haven't really explained it'; David Manheim: interpretability has 'never been used effectively to reduce misalignment at scale.' For your role: if interpretability becomes tractable with agents, auditing and steering a foundation platform gets much easier — treat this as an open bet with real upside, not a result.
